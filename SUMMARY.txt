Repo summary (local workspace)
==============================

This folder contains a compact BookNLP-based workflow for full-book analysis
and graph-oriented extraction.

What you can do (main outputs)
-----------------------------

1) Split a raw book into chapters (robust Gutenberg heading detection):
   - Writes: data/books/<book_id>/chapters/chapter_###.txt + chapters.json

2) Run BookNLP per chapter (big model, full pipeline):
   - tokens (POS + dependencies + token-level event tag)
   - entities (mentions + COREF cluster ids)
   - quotes (speaker attribution)
   - supersense (WordNet supersense labels)
   - book (JSON with characters + agent/patient/poss/mod lists)
   - native BookNLP HTML

3) Extract per-chapter derived JSON artefacts (no new NLP; uses BookNLP outputs):
   - characters_by_chapter.json: character counts + aliases per chapter
   - predicates_by_chapter.json: unordered character-pair -> predicates per chapter
   - sentences_by_pair_by_chapter.json: unordered character-pair -> concatenated co-occurrence sentences

4) (Optional) Run "classic" BookNLP on a single full-book .txt:
   - writes under data/booknlp_only_output/<run_id>/

5) (Optional) Generate an additional HTML listing page (read-only) that:
   - lists all BookNLP characters with agent/patient/poss/mod lists
   - shows event-tag counts from the tokens file
   - embeds a preview of extracted event triplets (if present)

6) (Optional) Extract event triplets for graph building:
   - (agent_character, predicate_lemma, patient_character) per verb event
   - written as TSV + JSONL, derived from BookNLP native outputs only

Key scripts (src/)
-----------------

- src/step1_split_only.py
  Chapter splitting for a raw .txt:
    data/books/<book_id>/chapters/chapter_###.txt

- run_booknlp_per_chapter.py
  Runs BookNLP on each chapter:
    data/booknlp_chapter_output/<book_id>/booknlp_<book_id>_chapter_0000/*

- src/step2_character_list_per_chapter.py
  Writes:
    data/booknlp_chapter_output/<book_id>/characters_by_chapter.json

- src/step3_predicates_between_characters.py
  Writes:
    data/booknlp_chapter_output/<book_id>/predicates_by_chapter.json

- src/step4_sentences_by_character_pair.py
  Writes:
    data/booknlp_chapter_output/<book_id>/sentences_by_pair_by_chapter.json

- src/run_booknlp_only.py
  Minimal runner for BookNLP on a single full-book .txt.
  Writes:
    data/booknlp_only_output/<run_id>/

- src/booknlp_listings_html.py
  Creates:
    <run_id>.book.listings.html
  from BookNLP native outputs:
    <run_id>.book + <run_id>.tokens
  and optional derived triplets:
    <run_id>.event_triplets.tsv/.jsonl

- src/booknlp_event_triplets.py
  Creates:
    <run_id>.event_triplets.tsv
    <run_id>.event_triplets.jsonl
  by reading BookNLP native outputs:
    <run_id>.tokens + <run_id>.entities + <run_id>.book

- src/graph_builder.py
  BookNLP wrapper with caching and Windows/transformers compatibility patches.

Data layout (local, mostly cache)
--------------------------------

data/booknlp_only_output/<run_id>/  : BookNLP outputs for full-book runs
data/booknlp_output/                : BookNLP cache for other runs (if present)
data/raw/                           : raw downloaded books (optional)
